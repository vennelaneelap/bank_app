BankApp Platform

C# Console and REST API (In Progress)

Technologies: C#, .NET 10, ASP.NET Core Web API, MongoDB, Swagger/OpenAPI, Object-Oriented Design, Git, GitHub

• Designed an object-oriented C#/.NET banking domain with abstract accounts, interfaces, inheritance,
encapsulation, checking/savings rules, and validated deposit, withdrawal, and transfer workflows.

• Extended the console application into an ASP.NET Core REST API, implementing customer and transaction
endpoints, request models, dependency injection, and Swagger/OpenAPI documentation.

• Added a MongoDB repository layer for persistent customer/account data and used Git feature branches to
separate console, no-database API, and MongoDB API development.
